# Recommended Mods and More

Never installed a mod for Bioshock before? It's easy squeezy! Most of them are installed via the [TFC installer](https://www.nexusmods.com/site/mods/588), which only takes a few clicks before your mods are up and running. However, it doesn't have a way to sort load order. So, install the mods in the order listed. Pick and choose the ones you'd like; these are just my recommendations for a smooth, modern VR experience!

### Skipping startup intros

For Bioshock 1 and 2, launch the game with -nointro parameter to skip the intros. For Bioshock Infinite, Download the replacement archive from [here](https://www.mediafire.com/download/8372k61bfwibek2) and then extract the archive to the installation folder and replace all files.
